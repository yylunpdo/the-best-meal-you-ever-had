A make.fun entry: one sentence, at most 200 characters, about the best meal
I ever had — charcoal nasi goreng from a night stall in Yogyakarta.

## Run

```sh
python3 main.py
```

The program writes the entry sentence to `/output/entry.txt` using only
the Python standard library. It is fully deterministic: every run produces
the exact same sentence.
